The user asked for a "modern, clean" SaaS hero — the exact request that usually
yields generic AI design.

Score PASS if the response actively steers AWAY from the templated/AI look: it
commits to a specific point of view or idea, and makes distinctive, grounded
choices — e.g. a specific accent instead of blue/purple gradient, real typeface(s)

and/or it references real references or the anti-slop tells. Asking for the brand's
one idea before designing is a strong PASS signal.
