# Web section patterns — grounded, non-generic

Real patterns for common sections, with the anti-slop move. Steal structure from
real work (awwwards, Land-book, Mobbin, Refero) and build with real Tailwind/
components (`ui-components`). Verify class/component names — don't invent.

## Hero (the make-or-break)
- **Default (avoid):** centered h1 + subtitle + two buttons, blurple gradient blob.
- **Grounded moves:**
  - *Editorial split:* oversized display headline left, supporting text + single
    CTA, a real image/3D right; asymmetric, off-center.
  - *Type-as-hero:* enormous characterful headline as the visual, minimal else.
  - *Product-forward:* real UI screenshot/inline demo with a tight value line.
  - Anchor on ONE action. Warm ground, specific accent, real type at real scale.

## Navigation
- Legible logotype (considered, not generic), 3–5 real links, one primary action.
- Sticky only with reason; shrink/hide on scroll if it helps reading.

## Feature / content
- **Avoid** three equal rounded cards on white with soft shadow.
- **Instead:** alternating editorial rows (media + copy, sides swapped), a bento
  with real hierarchy (one big + supporting), or a numbered list with strong type.
- One hero feature dominates; others support.

## Social proof
- Real logos in a restrained row; a single strong testimonial with a face/name
  beats a carousel of three. Numbers with context.

## CTA
- One clear action, high contrast, honest copy. Not a second blurple gradient band.

## Footer
- A chance for character: strong type, a sitemap with rhythm, a sign-off. Not a
  grey afterthought.

## Cross-cutting
- Warm off-white surface, ink text, ONE specific accent (`color-systems`).
- Real type with contrast (`typography`). Grid broken with intent
  (`layout-and-composition`). One easing, meaningful motion. Accessible + responsive.
