# Design research (senior methodology)

Distinctiveness is not invented from nothing — it comes from **studying real,
specific work and taking deliberate parts of it**. This skill is the anti-AI
engine: it grounds design in what real people shipped (`design-grounding`), which
is exactly what keeps output off the model's generic average. Hold the taste bar
with `distinctive-design`.

## Gather from real sources

Use the source registry (`design-grounding` → sources-registry;
[reference-sourcing](references/reference-sourcing.md) for how to mine each):
- **Web craft:** awwwards, Land-book, SiteInspire, Godly, Minimal.gallery, Httpster.
- **App UI/flows:** Mobbin (huge, login-gated), Refero, Page Flows.
- **Type in use:** Typewolf. **Visual mood:** Dribbble/Behance/Pinterest/ArtStation
  — vet hard for AI-slop and buildability.
- **Real code:** GitHub (component libs, awesome-lists, templates).

Access honestly: public → WebFetch/browser; API where available; login-gated →
ask the user for specific screens/boards. Don't fabricate what's behind a gate.

## Vet, don't hoard

For each reference ask: does it have a **point of view**? is it **real/shippable**
(vs a pretty concept shot)? is it **relevant** to the brief? Keep few strong ones,
drop generic ones. Dribbble especially rewards pretty-but-unbuildable — verify
against real shipping sites (awwwards/Mobbin).

## Extract, don't copy

For every keeper, name **what specifically** to take — the asymmetric masthead, the
type contrast, the color move, the spacing rhythm, the interaction — not "the
vibe". Combining specific moves from several real sources into one coherent idea is
design; copying one shot is plagiarism and looks it.

## Competitive analysis

Survey the space: what does everyone in this category do (the clichés to avoid),
and where's the opening to be distinctive? The goal is to look like it belongs and
stands out — not like the category template.

## Synthesize a direction

Turn the research into the design-direction schema (`design-grounding`): the one
idea, must-avoid, grounded palette/type, structural move, with linked references.
Drive it via `/design-studio:moodboard`.

## Reading it back

Reviewing research: are references real, linked, and vetted (not generic)? is each
tied to a specific move to steal? is there a synthesized idea, or just a pile of
screenshots? Name what's missing. Direction output → `/design-studio:moodboard`; critique
of a design → `visual-critique`.
