# Layout & composition (senior methodology)

Layout is the strongest lever against the AI look. The tell is **everything
centered, symmetric, equal weight, evenly padded**. Senior layout has hierarchy,
asymmetry with purpose, and whitespace used as a material. Follow
`distinctive-design`; steal real structure from real sites via `design-grounding`
(awwwards, Refero, Mobbin).

## Hierarchy first

Decide what's most important and make it *look* it — through size, weight, space,
and position, not just order. A page where everything shouts equally (three equal
cards, uniform sections) reads generic. One element should dominate each view.

## Grid, then break it

- Use a **real grid** (columns + gutters) for order — but the interest comes from
  **breaking it with intent**: an asymmetric masthead, an off-center hero, uneven
  column spans, an element that bleeds past the grid, deliberate overlap.
- Symmetry is calm but forgettable; asymmetry with balance is alive. Balance by
  visual weight, not mirror.

## Whitespace is a material

- Space is a design element, not leftover. Use it to **group and separate**: tight
  space where things relate, generous space where they don't. Uniform padding
  everywhere is the templated tell.
- Generous margins around a focal element create importance; density can create
  energy. Both are choices.

## Editorial thinking

Borrow from print/editorial: a strong masthead, a clear reading path, pull-quotes,
captions, rules/hairlines, columns of unequal measure. This is what separates
"designed" from "arranged into a template".

## Optical alignment (the senior detail)

- Align **optically**, not mathematically: an arrow or round shape often needs to
  push past the metric edge to *look* centered; icons beside text align to the
  visual center; punctuation hangs. `text-wrap: balance` on headlines, `pretty` on
  body. These corrections read as care.

## Rhythm & structure

- Establish a spacing scale (e.g. 4/8-based) and a vertical rhythm; consistent
  spacing is invisible and professional, random spacing looks amateur.
- Vary section structure — don't stack identical full-width bands. Alternate
  measure, offset, and density so the page has a cadence.

## Reading it back

Reviewing a layout: is there real hierarchy or equal-weight mush? a grid that's
broken with intent or dead-center symmetry? whitespace used as a material? optical
alignment? Name the templated tell and the fix, ideally with a real reference to
steal the structure from. Section-level patterns → `web-design`; responsive
behavior → `responsive-design`.
