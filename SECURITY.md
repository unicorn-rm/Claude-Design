# Security

## Nature of this plugin
Claude Design is a set of **methodology skills, agents, and commands** for Claude
Code. It produces design and front-end code and executes actions only through
Claude Code's normal tools, under your control.

## Notes
- The plugin references external design platforms and GitHub as sources; it fetches
  public pages and uses APIs where available, and treats login-gated sources as
  named references rather than scraping them.
- It does not store secrets or credentials.

## Reporting
If you find a security issue in the plugin content or tooling, please open a private
report to the repository owner (`unicorn-rm`) rather than a public issue.
